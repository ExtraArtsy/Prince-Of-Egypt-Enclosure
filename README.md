# Prince-Of-Egypt-Enclosure

Team Name: The Plague Doctors

Team Members: Nova Cano, Paulina Mroue

The goal of this project is to depict the sequence of events in The Prince of Egypt that led to the Hebrews being set free by Moses.
The project shows the sequences of Ramses and Moses' confrontation, the summoning of the ten plagues, the death of Ramses' son, and Moses' splitting of the Red Sea.
